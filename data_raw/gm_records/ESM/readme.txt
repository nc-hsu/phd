The esm_hdf5_download_manifest.csv is a record of all the esm hdf5 files that were 
able to be downloaded from the esm database web portal. In other words this files
identifies what esm records are able to be considered in the record selection and 
which not.

The original hdf5 files of all the esm records stored on our data server. 
The json files of the records used for this study are located in the "data_processed" folder
